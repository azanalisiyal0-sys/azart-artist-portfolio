# AZART — Artist Portfolio

A personal artist portfolio website showcasing original digital artwork and creative services.

## Overview

AZART is a responsive artist portfolio website designed to present digital artwork in a clean, minimal, and modern environment.

The website focuses on showcasing artwork while providing visitors with information about the artist, available services, and a way to request custom artwork.

## Website Pages

* **Home** — Introduction to AZART and featured artwork/services.
* **Portfolio** — Full artwork gallery with categories, search, filtering, and artwork details.
* **About** — Information about the artist, creative approach, skills, and development.
* **Services** — Available artwork and commission services.
* **Contact** — Contact and commission request form.

## Deployment

The website is designed to be hosted using GitHub Pages.

Before deployment, verify:

* All HTML pages load correctly.
* CSS and JavaScript paths are correct.
* Images load correctly.
* Navigation links work.
* Contact form works.
* Favicon loads.
* `robots.txt` is accessible.
* `sitemap.xml` is accessible.
* Mobile layouts work correctly.
* 404 page works correctly.
